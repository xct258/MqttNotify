## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

下划线形式（仅一、二级）：

```markdown
标题
====

标题
----
```

- 建议每篇只用一个 `#`；层级不要跳级（`#`→`##`→`###`）。
- `#` 与文字之间要有空格；标题前后留空行。

## 段落与换行

- 段落之间用**空行**分隔。
- 行尾加**两个及以上空格**或 `<br>` 可强制换行；GitHub 默认把单换行视为同一段。
- 正文不要用 Tab/四空格开头，会被当作代码块。

## 强调

```markdown
*斜体*        _斜体_
**粗体**      __粗体__
***粗斜体***
~~删除线~~
`行内代码`
==高亮==        （扩展，部分渲染器支持）
H~2~O           （下标，扩展）
x^2^            （上标，扩展）
```

## 列表

```markdown
- 无序项
+ 也可用 + 或 *
* 也可用 *

- 项目
  - 子项（缩进 2 或 4 空格）
    - 孙项
```

列表项内容跨多段时，后续段落与文字对齐缩进：

```markdown
- 第一段

  第二段（缩进对齐）
```

## 有序与嵌套列表

```markdown
1. 第一
2. 第二
3. 第三
   1. 子项（缩进后自动编号）
   2. 子项

1) 也可用右括号
```

在有序列表中可以混排无序子列表。

## 链接与图片

```markdown
[显示文字](https://example.com)
[带标题](https://example.com "悬停提示")
[引用式][ref] 和 [ref][] 和 [ref]

[ref]: https://example.com "标题"

<https://example.com>        自动链接
<user@example.com>

![替代文字](img.png "标题")
![引用式图片][img]

[img]: img.png
```

图片加链接：`[![alt](img.png)](https://example.com)`。

## 代码

行内：`` `print("hi")` ``（用多个反引号可包含反引号：`` `` `code` `` ``）。

围栏代码块：

````markdown
```python
def hello():
    print("hi")
```
````

- 语言标识：`bash` `python` `json` `yaml` `sql` `html` `js` `diff` 等。
- 用 ```` ``` ````（四个及以上）可嵌套包含三个反引号的代码。
- 缩进四空格也可表示代码块，但无法标语言。

## 引用

```markdown
> 一级引用
>> 嵌套引用
>
> 引用内可放列表：
> - 项一
> - 项二
```

引用内可包含标题、代码、表格等。

## 分隔线

```markdown
---
***
___
```

三个及以上 `-`、`*`、`_` 单独成行，前后建议留空行（否则可能被当作标题下划线或列表）。

## 表格

```markdown
| 名称 | 类型 | 说明 |
|:-----|:----:|-----:|
| id   | int  | 编号 |
| name | str  | 名称 |
```

- 对齐：`:---` 左、`:---:` 中、`---:` 右。
- 表格前需空行；列数由分隔行决定；单元格内 `|` 用 `\|` 转义。
- 扩展（部分渲染器）：单元格可换行、可合并。

## 任务列表

```markdown
- [x] 已完成
- [ ] 未完成
- [ ] 待办
```

仅 GitHub / 部分渲染器支持，渲染为复选框。

## 脚注

```markdown
正文引用[^1] 和 [^note]。

[^1]: 第一条脚注。
[^note]: 命名脚注，可有多段。
```

## 定义列表

```markdown
术语
: 定义内容

Markdown
: 一种轻量标记语言
: 有多个定义时写多行
```

部分渲染器支持。

## 锚点与目录

- 标题会自动生成锚点，如 `## 标题` → `#标题`（中英文均可，空格转 `-`）。
- 手动锚点：`<a name="top"></a>` 或 `<a id="top"></a>`。
- 跳转：`[去标题](#标题)`；返回顶部 `[顶部](#)`。
- 自动目录：部分平台支持 `[TOC]`；其余需手动或用工具生成。

## 转义字符

以下字符前加 `\` 输出字面值：

```text
\ 反引号` 星号* 下划线_ 花括号{} 方括号[] 圆括号()
# 加号+ 减号- 点. 感叹号! 竖线| 大于号>
```

例：`\*不是斜体\*` 显示为 *不是斜体*。

## 内嵌 HTML

```html
<br>  <hr>
<div align="center">居中</div>
<sup>上标</sup> <sub>下标</sub>
<kbd>Ctrl</kbd>+<kbd>S</kbd>
<details><summary>点击展开</summary>隐藏内容</details>
<img src="img.png" width="200">
<span style="color:red">红色文字</span>
```

注意：出于安全，GitHub 等只允许白名单标签，会过滤 `style`/`script`。

## 扩展语法

- **数学公式**：`$行内$`、`$$ 块级 $$`（KaTeX/MathJax，本编辑器不渲染）。
- **流程图**：` ```mermaid ` 代码块（GitHub / Typora 支持）。
- **Front Matter**：文件开头的 YAML 元信息。

```markdown
---
title: 我的文档
date: 2024-05-01
tags: [a, b]
---
```

- **缩写**：`*[HTML]: 超文本标记语言`。
- **目录**：`[TOC]`（部分平台）。
- **自动链接**：`https://example.com` 直接成链接（扩展）。

## 平台差异

| 语法 | GitHub | Typora | VS Code 预览 | 说明 |
|------|:---:|:---:|:---:|------|
| 表格 / 任务列表 / 删除线 | ✓ | ✓ | ✓ | 常见扩展 |
| 脚注 | ✓ | ✓ | ✓ | |
| 数学公式 | ✓ | ✓ | ✗ | 需插件 |
| Mermaid | ✓ | ✓ | ✗ | |
| `[TOC]` | ✗ | ✓ | ✗ | 需手动目录 |
| HTML 过滤 | 严格 | 宽松 | 中等 | |

- **软换行**：GitHub 单换行不断行，CommonMark 合并；需要断行用行尾两空格。
- **图片对齐/尺寸**：多用 HTML `<img width>` 或扩展属性。

## 写作建议

- 标题不跳级；列表/代码/表格前后留空行，兼容性最好。
- 一篇文档开头加目录；文件名与锚点保持简单一致，便于跳转。
- 列表统一用 `-`，强调统一用 `*`/`**`，避免与分隔线混淆。
- 代码块标注语言以获得高亮。
- 需要精确排版时才用 HTML；优先纯 Markdown，跨平台更稳。
- 用空行分隔块级元素；避免行首行尾多余空格（除刻意换行）。
